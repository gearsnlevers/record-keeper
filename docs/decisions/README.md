# Decision records

The decisions of Record Keeper itself. The protocol the kit enforces is decided in record 0001, and the rest follows from it: an accepted record is not edited, it is superseded.

The protocol has a generation, and a seal names the generation it was made under. The record in force is the last accepted row.
